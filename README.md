# Install Factorio demo on Linux
A script that will install the latest [Factorio](https://factorio.com/) demo version on Linux

This script can be run in two ways: Full installation and standalone installation.

## Full installation
1. Download the script
2. Run the following commands in a terminal
   1. cd &lt;Download folder&gt;
      - Note: This folder must be writable
   3. chmod +x "./Install Factorio demo on Linux.sh"
   4. sudo "./Install Factorio demo on Linux.sh"
3. Wait for the installation to complete (It may take a while)
4. Factorio can now be run using the desktop icon or the "factorio" command in a terminal

## Standalone installation
1. Create a folder where Factorio should be installed
2. Download the script and move it to the new folder
3. Run the following commands in a terminal
   1. chmod +x "./Install Factorio demo on Linux.sh"
   2. "./Install Factorio demo on Linux.sh"
3. Wait for the installation to complete (It may take a while)
4. Factorio can now be run using the desktop icon
